🔧 一个小作品

写了个 cpu_temp.py，跑在 RISC-V 板子上实时监视 CPU 温度。 每隔一秒读一次 /sys/class/thermal/thermal_zone0/temp， 超过 75°C 就用红字警告，正常显示绿色。 在 SSH 终端里跑起来像个小仪表盘，直观又省资源。

#!/usr/bin/env python3 import time, os TEMP_PATH = "/sys/class/thermal/thermal_zone0/temp" def read_temp(): with open(TEMP_PATH) as f: return round(int(f.read()) / 1000, 1) while True: temp = read_temp() flag = "🐱" if temp < 75 else "🔥" color = "\033[92m" if temp < 75 else "\033[91m" print(f"{color}{flag} CPU: {temp}°C\033[0m") time.sleep(1)
